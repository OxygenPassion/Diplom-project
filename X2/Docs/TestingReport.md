# Отчет о тестировании программного средства

**Тема ВКР:** Разработка системы управления учебным процессом ВУЗа  
**Объект тестирования:** приложение X2 для формирования расписания занятий  
**Вид тестирования:** ручное функциональное тестирование  
**Среда тестирования:** Windows 10 и выше, .NET Framework 4.8, Microsoft SQL Server  

## Цель тестирования

Целью тестирования является проверка корректности работы основных функций программного средства, связанных с вводом исходных данных, формированием расписания занятий, проверкой конфликтов, редактированием и повторным изменением данных.

Проверки составлены на основе раздела 4.5 технического задания и покрывают следующие требования:

- корректный ввод и сохранение данных о дисциплинах, преподавателях, учебных группах и аудиториях;
- формирование расписания при различных наборах исходных данных;
- отсутствие пересечений по времени занятий;
- контроль занятости преподавателей;
- контроль занятости аудиторий;
- контроль занятости учебных групп;
- корректное редактирование и обновление расписания;
- устойчивость работы системы при повторном изменении данных;
- формирование и отображение расписания за время не более 3 секунд.

## Вывод

В ходе тестирования были проверены основные функциональные возможности программного средства: ввод и сохранение исходных данных, формирование расписания, проверка логических конфликтов, редактирование расписания, повторное изменение данных и отображение результата.

Результаты тестирования подтверждают корректность формирования расписания занятий и отсутствие логических конфликтов по времени, преподавателям, аудиториям и учебным группам. Критических ошибок, препятствующих использованию программного средства, не выявлено.
