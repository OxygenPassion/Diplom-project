# Краткое описание проекта для защиты

**Тема:** Разработка системы управления учебным процессом ВУЗа  
**Проект:** X2  
**Тип приложения:** настольное приложение Windows Forms  
**Язык и платформа:** C#, .NET Framework 4.8  
**СУБД:** Microsoft SQL Server  
**Доступ к данным:** ADO.NET, `System.Data.SqlClient`  

## Назначение системы

Программное средство предназначено для автоматизации формирования расписания занятий ВУЗа. Система позволяет вести справочники преподавателей, дисциплин, учебных групп и аудиторий, формировать учебный план, генерировать расписание, просматривать его и вносить корректировки.

## Основные файлы проекта

|---|---|

| `Class/ScheduleConflictChecker.cs` | Проверка занятости группы, преподавателя и аудитории |
| `Class/CombinedScheduleGenerator.cs` | Алгоритм генерации расписания |
| `Class/ScheduleService.cs` | Добавление, изменение и удаление занятий расписания |

## Что можно показать на демонстрации

1. Запуск приложения и вход под пользователем `admin` / `admin`.
2. Добавление группы, аудитории, дисциплины и преподавателя.
3. Назначение преподавателю дисциплины.
4. Формирование учебного плана для группы и семестра.
5. Генерация расписания.
6. Просмотр расписания.
7. Попытка создать конфликт по преподавателю, аудитории или группе.
8. Редактирование существующей записи расписания.

## Итог

Проект реализует основные функции, заявленные в техническом задании: хранение исходных данных, формирование расписания, проверку конфликтов, просмотр и редактирование результата. Дополнительные материалы `CreateDatabase.sql` и `TestingReport.md` закрывают требования к информационному обеспечению и тестированию.
